I Lost My Weights

This is a AI challenge :O

First step of any AI challenge is to know the format of our data set. Looking at the data set, the data in train_x and test_x are stored as a float, while the data in train_y are stored as an integer of either 0 or 1. This suggests that this is a binary classification problem, and a classifier is more appropriate to solve this problem rather than a regressor.

Using scikit-learn in Python, the training data set can be split (aka. train_x and train_y) into 70-30. 70% of the training data would be used to train the model while 30% would be used to evaluate the model (determine how good the model is).


    from sklearn.model_selection import train_test_split

    X_train, X_test, y_train, y_test = train_test_split(train_x, train_y, test_size=0.3, random_state=42)

There are a lot of classifiers that can be used to solve the problem (or you can implement your own neural net if you want a challenge). I personally went with Random Forest Classifier, which gave a R-squared score of 0.96333. Predicting test_y based on test_x, the resultant array also consists of a series of 1s and 0s (who would have guessed :O). Given that this is still a CTF challenge, the flag is probably masked under the test_y prediction. By converting test_y into a binary string, and converting to text, the flag is obtained. 



    from sklearn.ensemble import RandomForestClassifier

    # train and evaluate model
    model = RandomForestClassifier()
    model.fit(X_train, y_train)
    print(model.score(X_test, y_test))

    # predict test_y based on test_x and convert to binary string
    test_y = model.predict(test_x)
    test_y = map(str, test_y)
    binary_string = ''.join(test_y)

    # convert from binary string to text
    for i in range(0, len(binary_string), 8):
        print(chr(int(binary_string[i: i+8], 2)), end='')
